Build the roster before assigning roles. The students in **Roster** become the choices available for default and pairing-specific assignments.

## Add a coach

1. Open your team and select **Coaches**.
2. Select **Add coach**.
3. Enter the coach's name and email address.
4. Select **Add coach**.

The added coach must already have a MockScores account. The **Status** column shows whether the coach has joined.

The team owner cannot be removed. Other coaches can be removed from the team. Only an organizer using the team's organizer view can select **Make Owner** and transfer ownership to a joined coach.

## Control notifications

Joined coaches have a notification toggle in the **Coaches** table. Select the icon to enable or disable that coach's team notifications. Pending invitees do not have a notification setting until they join.

## Add students

1. Select **Roster**.
2. Enter the student's name.
3. Choose the student's pronouns, or select the custom option and enter them.
4. Select **Add**.

Every student needs a name and a pronoun selection. The student's name and pronouns may appear on scorer ballots when the student is assigned to a role.

Use **Remove** to delete a student after confirming they should no longer be on the roster.

:::caution
Before removing a student, review the team's default and pairing-specific assignments. A removed student can no longer fill those roles. If a student has received award nominations, those nominations may be lost.
:::

## Complete custom roster fields

The organizer may add extra columns, such as grade level or competition experience. Text fields accept text and number fields accept numeric values.

Enter each value in the student's row, then move out of the field to save it. Leaving a field blank removes its saved value.

Contact the organizer if a required roster column is missing or uses the wrong type; coaches cannot change the column definitions.

## Save default call orders and roles

At the bottom of **Roster**, select one of:

- **Set Prosecution Call Order & Assignments** or **Set Plaintiff Call Order & Assignments**, depending on the case type.
- **Set Defense Call Order & Assignments**.

In the setup window:

1. Choose a different witness for each call position.
2. Assign a student to each role that your team expects to use.
3. Select **Save**.

The available positions and roles come from the tournament's witness and scorecard configuration. Swing witnesses are marked as swing witnesses.

Defaults provide a starting point for every pairing. Pairing-specific choices can override them until the round is locked. If no pairing-specific values are saved, the organizer's lock action copies the defaults into the round.

## Preparation checks

The **Overview** page identifies missing default assignments, call orders, and pairing-specific preparation. Before a round is locked, confirm that:

- Every competing student is on the roster.
- Organizer-defined roster fields are complete.
- Default assignments cover both sides your team may represent.
- Default call orders use the correct number of witnesses.
- The published pairing has been reviewed separately.
