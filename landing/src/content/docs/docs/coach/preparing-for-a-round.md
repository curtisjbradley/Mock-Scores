When an organizer publishes pairings, the round appears in **Schedule**. Each pairing shows the two teams, courtroom, and controls for your team's preparation.

## Review the pairing

Before assigning roles, confirm:

- Your opponent is correct.
- Your team is shown on the correct prosecution/plaintiff or defense side.
- The courtroom is correct or marked **TBD**.
- The round time is correct or marked **Time TBD**.

Contact the organizer before preparing if any pairing information is wrong.

## Assign students to roles

1. Open **Schedule**.
2. Select **Assign Roles** for the pairing. If assignments already exist, the button reads **Edit roles**.
3. Review each category and role.
4. Choose the student performing each role.
5. Select **Save**.

The form shows only roles that the organizer marked assignable and that apply to your side. Witness categories are grouped by witness, including the calling and crossing roles configured on the tournament scorecard.

Saved defaults are loaded first, and pairing-specific assignments appear over them. Saving the page records the current assigned rows for this pairing.

## Set the witness call order

1. Return to **Schedule**.
2. Select **Assign Call Order**. If an order already exists, the button reads **Edit call order**.
3. Choose one witness for each numbered call position.
4. Select **Save**.

The number of positions is set by the organizer. Only witnesses available to your side are listed, including swing witnesses. Selecting a witness in one position clears that witness from any other position so a witness is not called twice.

## Edit before the lock

You may reopen either page and make changes until the organizer locks the round. A locked round displays a **Locked** badge and disables both controls.

After locking, the buttons show whether MockScores used your pairing-specific preparation or copied the team's defaults:

- **Roles Assigned** or **Copied Default Roles**
- **Call Order Set** or **Copied Default Call Order**

:::danger
The lock is permanent. If you need a change after the round is locked, contact the organizer immediately. The coach interface cannot edit the assignments or call order.
:::

## If a role or witness is missing

The organizer controls the scorecard, witness list, and number of witnesses called. Contact the organizer if:

- A required role does not appear.
- A witness is missing or listed on the wrong side.
- There are too many or too few call-order positions.
- The case uses the wrong prosecution or plaintiff label.

Do not substitute a different role or witness simply to complete the form; the ballot is generated from the same tournament structure.
