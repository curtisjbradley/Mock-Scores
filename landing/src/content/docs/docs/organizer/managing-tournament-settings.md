Tournament settings can be changed after creation. Open the tournament, select **Structure**, then select **Tournament Details**.

## Edit tournament details

The settings form contains:

- **Tournament name** and **Location**, which are required.
- **Start date** and **End date**, each of which may be marked **TBD**.
- **Case name**, which is required.
- **Criminal case**, which changes the first side's label between **Prosecution** and **Plaintiff**.
- **Share individual rankings**, which lets coaches see award nominations on released ballots.

Select **Save** after making changes. When both dates are set, the end date must not be before the start date.

:::note
Tournament dates are informational. Round start times are configured separately in **Rounds**.
:::

## Change tournament status

The tournament owner can set one of three statuses:

| Status        | When to use it                                                                  |
|---------------|---------------------------------------------------------------------------------|
| **Active**    | The tournament is being prepared or is currently running.                       |
| **Completed** | Competition has ended, but the tournament should remain easy to find.           |
| **Archived**  | The tournament is no longer active and should be separated from current events. |

From the tournament settings page, use **Reactivate**, **Mark completed**, or **Archive**. On the organizer dashboard, use the **All**, **Active**, **Completed**, and **Archived** filters to find tournaments by status.

## Duplicate a tournament

Duplicating is useful when a new tournament will reuse an earlier event's structure.

1. Return to the main organizer dashboard.
2. Find the tournament you want to copy and select **Duplicate**.
3. Choose which parts to copy:
   - Case format
   - Witnesses
   - Scoring categories
   - Award categories
   - Scorers
   - Courtrooms
   - Tiebreakers and standings
4. Select **Duplicate**.
5. Open the new tournament and update its name, location, dates, and case information.

Teams, rounds, pairings, ballots, and submitted results are not listed as duplication options. Add or create them for the new event.

:::tip
For an annual competition, duplicate the prior tournament and copy only the structures that are still governed by the same rules. Review every copied score field and tiebreaker before inviting teams.
:::

## Delete a tournament

Only the tournament owner can see the **Danger zone** and delete the tournament.

Deleting makes the tournament, its configuration, and its scorecards permanently unavailable. This action cannot be undone. If the event is merely finished, use **Mark completed** or **Archive** instead.

## Troubleshooting

### I cannot change the status or delete the tournament

Those controls are shown only to the tournament owner. Ask the owner to make the change.

### The settings will not save

Confirm that the tournament name, location, and case name are present. If dates are not marked **TBD**, both must be entered and the end date must be on or after the start date.
