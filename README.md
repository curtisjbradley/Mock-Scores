# Mock-Scores

[![codecov](https://codecov.io/gh/curtisjbradley/Mock-Scores/branch/main/graph/badge.svg)](https://codecov.io/gh/curtisjbradley/Mock-Scores)


Mock-Scores is an open source project designed to provide scoring and tabulation software to high school and collegiate mock trial programs.

The goals of the project are:

* Ease of Use 
* Customizability for Tournament Organizers
* Transparency for Coaches
